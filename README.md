# QuadTap 四格映射（Android V1.5）

QuadTap 是一个 Android 悬浮点击与选项位置识别原型。它把屏幕上的选项位置映射到固定的 A/B/C/D 四格悬浮面板上：
你按下面板上的某一格，它在当前页面找到对应选项的坐标并点击过去。

**它不会判断答案。** 本工具只做「按键 → 坐标」的映射，选什么完全由你决定。

## 定位优先级

1. **字母匹配** —— 扫描当前窗口和所有可交互窗口里的控件文本，识别 `A. 加速通过`、`B、停车让行`、`(C)`、`选项D` 等写法；
2. **位置兜底** —— 字母一个都匹配不上时启用。有些题库（例如驾考宝典 `com.handsgo.jiakao.android`）
   把 A/B/C/D 渲染成图片，文字节点里只有选项正文，任何要求字母的规则都不可能命中。
   这时按几何特征找出一列**等宽、等距、高度接近**的选项行，从上到下依次对应 A/B/C/D；
3. **手动校准记录** —— 使用你长按格子时记录的位置；
4. **截屏 + 中文 OCR** —— Android 11 及以上，且前三步都失败时，截图做本机文字识别。

## 功能

- A/B/C/D 四格悬浮面板，使用 `TYPE_ACCESSIBILITY_OVERLAY`，**不需要「显示在其他应用上层」权限**；
- **限定显示的应用**：可以选定若干应用，面板只在这些应用位于前台时出现。
  切到别的应用时面板会被**真正移除**（`removeView`，不是设成透明），
  所以既不遮挡，也不会在它覆盖的位置吞掉触摸事件；
- **面板可拖动**，松手后自动吸附到屏幕左右边缘，位置会被记住；
- **长按格子手动校准**：面板暂时隐藏，你直接点屏幕上该选项的真实位置即可记录。
  取点层是透明的，**不会真的点到目标应用**，因此不会误作答，也不依赖目标应用是否发送无障碍点击事件；
- 点击格子在屏幕上短暂画出本次识别到的选项范围，方便确认映射是否正确；
- 校准坐标按屏幕宽高的**相对比例**保存，旋转屏幕或换机后仍然可用；
- 设置页显示服务真实状态（是否开启 / 是否已连接 / 已校准数量 / 上次扫描结果）和三个开关；
- **方块大小可调**（34–76 dp），松手即时生效，面板按新尺寸重建且位置不变；
- **输入法弹出时自动隐藏面板**，避免打字时挡住候选栏；
- 设置页为卡片式布局，操作流程、技术说明和更新日志都写在应用内；
  诊断日志与关于信息可折叠，不会占满整屏。
- **诊断日志**：每次点击悬浮格都会把当次扫描的完整无障碍节点树、候选评分、逐条判定过程和 OCR 结果
  写进应用内的环形缓冲（最多 800 行，只存在内存里），可在设置页查看、复制或分享；
- 自动与手动识别之间有并发护栏，避免连点叠出多路截屏。

## 识别不准时怎么办

设置页底部有「诊断日志」区，点「复制」把内容发出来即可定位问题。日志里包含：

- 所有窗口的类型、层级、包名，以及哪些因为属于本应用而被跳过；
- 遍历到的每一个带文本的节点：文本原文、屏幕坐标、是否可点击、深度；
- 每个标签（A/B/C/D）的候选列表和各自评分，以及最终选中了哪一个；
- OCR 回退是否触发、截屏是否成功、识别出的每一行文字及其坐标和匹配结果；
- 最终点击坐标，以及它的来源（节点定位 / 已校准位置 / OCR）。

## 已知限制

- **验证范围有限**：目前只在驾考宝典（`com.handsgo.jiakao.android`）上实测过。
  定位逻辑是按常见题库界面结构写的，换成别的应用很可能需要重新调整；
- 位置兜底靠的是几何特征（同列、等宽、等距）。如果目标应用把选项排成两列网格、
  或各选项宽度不一致，兜底就会失效，此时只能长按手动校准；
- OCR 回退依赖 Android 11+ 的截屏 API，系统版本更低时只有自动节点定位和手动校准两条路；
- OCR 对题型措辞、字体、背景对比度敏感，识别不到时会提示你改用长按校准；
- 判断题（正确/错误）只在没有 A–D 字母时按「正确→A、错误→B」处理；
- 四个标签的纵坐标顺序矛盾时**只记录日志、不再丢弃结果**（V1.2 起），
  所以极端情况下可能点到错误的选项；
- 发布的是 **debug 签名**的 APK，仅供自用测试，不适合上架分发；
- Android 系统版本、目标应用界面结构、无障碍策略和厂商定制都会影响效果。

请先在你有权操作的应用中进行安全测试，并在确认映射准确后再使用。

## 技术方向

- Java / Android SDK（minSdk 26，compileSdk 35）
- Android AccessibilityService（`canRetrieveWindowContent` / `canPerformGestures` / `canTakeScreenshot`）
- Android 屏幕截图 API（API 30+），HARDWARE 位图转 ARGB_8888 软件位图
- Google ML Kit 中文文字识别

## 下载

已发布的版本见 [Releases](https://github.com/yuyibei2023/QuadTap/releases)。
每个版本附带 APK 和 `SHA256SUMS.txt` 校验文件，
文件名是 `QuadTap-v<版本>-release.apk`（已配正式签名）或 `QuadTap-v<版本>-debug.apk`（未配签名时回退）。

关于正式签名是什么、怎么配，见 [`docs/SIGNING.md`](docs/SIGNING.md)。

打标签即可自动发布：

```
git tag v1.5
git push origin v1.5
```

`.github/workflows/release.yml` 会自动构建 APK、生成校验文件，
并从下面这份变更记录里取出对应版本的段落作为发布说明。不需要配置任何个人令牌。
