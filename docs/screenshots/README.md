# 应用截图

把截图放进这个文件夹,发布 Release 时会**自动**附到发布说明里。

## 怎么生效

1. 把 PNG / JPG 放进 `docs/screenshots/`
2. 提交并推送(推到 `main`)
3. 下次打标签发版时,`release.yml` 会自动在发布说明末尾追加「界面截图」区

图片地址固定指向 `main` 分支(不是标签),所以**先加图片、后发版**最稳妥。
如果已经有了 release,加完图片重新打一次同一个标签即可刷新说明。

## 需要的截图

建议按下面的文件名放,`captions.txt` 里已经预置好对应标题,不用改就能用:

| 文件名 | 内容 |
|---|---|
| `01-home.png` | 首页整体,能看到状态卡片和操作流程 |
| `02-panel.png` | 题目页面上悬浮的 A/B/C/D 面板(最好是 4 选项题) |
| `03-calibrate.png` | 长按格子后的取点层:半透明遮罩 + 提示文字 |
| `04-log.png` | 诊断日志展开后的样子 |
| `05-app-picker.png` | 选择应用的多选对话框 |

不想要某一张就删掉对应文件,或者改 `captions.txt` 里的标题。

## 注意事项

- **文件名尽量用 ASCII**(`01-home.png`),中文文件名在 URL 里要转义,容易出问题
- 截图里**不要露出个人隐私**(手机号、真实姓名、聊天内容等)
- 建议竖屏截图,宽度 720–1080px 就够,不必原图

## 想改标题

编辑同目录下的 `captions.txt`,格式是 `文件名=标题`,一行一条:

```
01-home.png=首页
02-panel.png=悬浮面板
```

只在 `captions.txt` 里没有对应条目时,才会退回用文件名当标题。

## 手动加进 README(可选)

README 里的相对路径可以直接用,把下面这段粘到你想要的位置即可:

```markdown
## 界面截图

| 首页 | 悬浮面板 | 手动校准 |
|---|---|---|
| ![首页](docs/screenshots/01-home.png) | ![悬浮面板](docs/screenshots/02-panel.png) | ![手动校准](docs/screenshots/03-calibrate.png) |
```
